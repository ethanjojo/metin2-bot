# Changelog

## 0.1.0-rc.1 — Rust Windows prerelease

- Replace the Python/Tkinter application with a Rust/egui desktop application.
- Preserve legacy profile import, recognition, target tracking, scheduling, mount state and guarded Windows input.
- Introduce Run, Calibration, Buffs and Settings with canvas tools, explicit editing states and vector icons.
- Add searchable, remembered per-profile game-window selection, window-only Windows capture and detection previews.
- Improve skill ordering/deletion, icon capture, color editing, crop validation, area dimensions and zoom.
- Add themed application branding, Windows taskbar updates, Linux desktop integration and macOS bundle/Dock implementation.
- Convert release automation to Rust with native dependency/license inventories, ZIP/installer checksums, hosted installation/upgrade/uninstall checks and download verification.

This is not a stable/gameplay-accepted release. Linux/macOS automation is unavailable. macOS native runtime, hosted clean-machine acceptance and real-game acceptance remain open until their checks run successfully.
