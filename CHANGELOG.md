# Changelog

## 0.1.0

First stable Companion release for Windows: a Metin2 bot with a compact Metin-style interface.

- Choose a game window, keep separate profiles and select recognition areas directly over the game.
- Detect Metins using color presets and a fixed HP-panel detail, with optional target outlines and exclusions.
- Configure ordered timed/image-based buffs, loot, mount behavior, periodic actions, visual rules, auto-puller and out-of-target attacks.
- Set stop limits, breaks, recovery attempts and local notifications. Follow countdowns, complete-cycle statistics and event history in Run.
- Review logical unsaved edits with Saved/Edited comparisons, color/image previews and exact setting links.
- Check HP/buff recognition in a separate dialog without sending input or extending live buff evidence.
- Remember panel size/position, use percentage UI scale, and duplicate or export/import profiles with reference images.
- Check and install updates inside Companion with data backups and a paused restart. Fix Windows error 33 during backup preparation.
- Simplify user documentation around setup and app options, with separate action and installation guides.
- Use the white Companion mark consistently in the app, Windows taskbar/Start shortcuts and setup.

## 0.1.0 preview series

The review and release-candidate builds introduced the compact panel, direct game selection, guarded input, actions, recognition tools and integrated updater. Their fixes and UI refinements are included in 0.1.0. Individual preview changes remain available in [GitHub releases](https://github.com/ethanjojo/metin2-bot/releases) and Git history.
