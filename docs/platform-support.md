# Supported platform

Companion is a Metin2 bot for **Windows x64**. Linux and macOS desktop builds are not supported.

| Requirement | Supported |
| --- | --- |
| Windows | Windows 10 version 2004 / build 19041 or newer, including Windows 11 |
| Architecture | 64-bit Intel or AMD |
| Graphics | Direct3D 11-capable device |
| Installation | CompanionSetup with administrator approval |
| Input | Required shared HIDMaestro 2.1.0 driver, installed by setup |

Libraries are included. Users do not need Rust, development tools or a separate .NET runtime.

Keep the selected game visible and in the foreground. Switching to another app pauses gameplay input. The compact panel and target overlay do not provide background gameplay control.

Windows may show a capture border when privacy settings do not allow borderless capture.
